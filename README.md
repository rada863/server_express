# server_express - TP_UNTRESF

Servidor backend desarrollado con **Express.js** para el trabajo práctico de la materia UNTRESF. El proyecto implementa una API REST con controladores, rutas y una capa de datos, culminado sin fallas.


## 📁 Estructura del Proyecto

- `server_express/`
  - `controller/` → Lógica de negocio y controladores
  - `data/` → Archivos JSON / base de datos local
  - `routes/` → Definición de rutas de la API
  - `src/` → Configuración principal u otros módulos
  - `node_modules/` → Dependencias instaladas por npm
  - `Guamini-Pra769ctico-2.md` → Documento de práctica / guía
  - `package.json` → Metadatos del proyecto y scripts
  - `package-lock.json`
  - `README.md` → Documentación del proyecto
